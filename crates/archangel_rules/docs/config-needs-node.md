# config-needs-node

The config is TypeScript or JavaScript, and Node 22.18 or later is not on the search path.

## Example

```sh
config-needs-node: the `node` on the search path is version 20.11.0, and archangel needs 22.18 or later
```

## What to do

Install Node 22.18 or later, or write the config as `archangel.config.json`, which needs no Node.
