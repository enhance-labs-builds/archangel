# Code of conduct

Archangel follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and argue about the code rather than the person. Harassment,
insults and personal attacks are not tolerated, in issues, pull requests or anywhere the project
meets.

Report conduct that breaks it privately to a maintainer, through the contact on their GitHub profile.
Every report is read, and the reporter's identity stays private.
