This guide checks the names of files and folders, and which files a folder must hold.

## Before you start

## Write the rules

This config has five rules. The sections below tell you about each one.

<Example fixture="names" file="archangel.config.ts" />

### A style for folders

`folder-names` uses `folders`, not `files`. The pattern `src/**` matches each folder inside `src`.
`mustBeNamed: 'kebab-case'` gives the style.

The styles are `kebab-case`, `camelCase`, `PascalCase`, `snake_case` and
`SCREAMING_SNAKE_CASE`.

### A style for files

`component-names` gives each component file a name in `PascalCase`. For a style, archangel reads
the name up to the first dot. So `Avatar.tsx` has the name `Avatar`, and `Button.test.tsx` has the
name `Button`.

### A list of permitted names

`ui-file-names` permits two name patterns: `*.view` and `*.container`. A name pattern reads the
full name of the file without its last extension, so `cart.view.tsx` has the full name
`cart.view`. In a name pattern, `*` is any text or no text.

- `*.view` matches `cart.view.tsx`.
- `*.view` does not match `view.tsx`, whose full name is `view`.
- `*.view` does not match `cart.view.extra.tsx`, whose full name is `cart.view.extra`.

One entry of the list must match. A list can mix styles and name patterns. An empty list is a
config error.

### A file exports the name of its file

`component-exports` uses an export condition: `mustExport: '{FileName}'`. `{FileName}` is the name
of the file in `PascalCase`. So `Avatar.tsx` must export `Avatar`. A re-export and `export *` count.

The name of the file or its folder can go in a name pattern in each style: `{FileName}`,
`{fileName}`, `{file-name}`, `{file_name}`, `{FILE_NAME}`, and the same spellings of
`{FolderName}`.

### Each folder has its entry file

`feature-entry` uses `mustContain`. Each folder that `src/features/*` matches must hold
`index.ts`. To permit one file of a list, write a list:
`mustContain: ['index.ts', 'index.tsx']`.

The end of the output lists one file and three imports that no rule judges. Name rules judge
files, not imports. To check the imports too, add a table.

## What archangel does not check

- Archangel has no rule for the first or the last character of a name, for example a name that
  starts with `_`.
- Archangel does not check the names inside a file, such as names of functions. `mustExport` and
  `mayNotExport` check only exported names.
