This guide keeps server-only code out of the browser in a Next.js app, with the `nextjs` preset.

## Before you start

- Read [Getting started](/archangel/start/getting-started/).
- You have a Next.js app that uses the App Router and `'use client'` files.

## What the preset checks

A file that starts with `'use client'` runs in the browser. So does each file that it reaches
through runtime imports. The preset refuses a chain of imports from a client file to the package
`server-only` or to a Node built-in module, such as `node:fs`.

A chain stops at a file that starts with `'use server'`. Next.js changes an import of a server
action into a network call, so the code of the action does not go to the browser.

The preset has one rule, `nextjs/client-stays-client`. It counts only runtime imports, because the
compiler removes an `import type`.
